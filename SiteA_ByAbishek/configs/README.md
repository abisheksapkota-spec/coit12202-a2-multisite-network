# Configs

Exported and written configuration for Site A's devices.

- OPNsense1 and OPNsense2 - exported config.xml or a written summary of interface/rule settings (console can't export config.xml directly; document the settings manually if needed).
- Kerberos build record - realm, principals, keytab steps, checkpoints (same pattern as the original Kerberos summary).
- Host/VPNRouter1/IDS1 `/etc/network/interfaces` content, for reference.
- Suricata ruleset notes, once configured.

Naming convention: `<device>-config.md` or `<device>-<detail>.txt`, e.g. `opnsense1-config.md`, `kerberos-summary.md`.
