# Site B Configuration Evidence

This folder contains configuration documentation and supporting configuration evidence for Site B.

Site B includes configuration for:

- OPNsense firewall and network interfaces
- Kerberos authentication
- Tailscale VPN connectivity
- Suricata IDS
- SSH services
- PKI and HTTPS services

Sensitive information such as passwords, private keys, authentication tokens, and other credentials should not be committed to this repository.

Configuration files and sanitized configuration evidence for Site B can be stored in this folder.
